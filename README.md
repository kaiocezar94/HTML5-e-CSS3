🌐 Meu Projeto — HTML5 e CSS3

Projeto desenvolvido durante os meus estudos de HTML5 e CSS3, com o objetivo de colocar em prática os principais conceitos aprendidos no curso do Gustavo Guanabara.

O projeto foi desenvolvido de forma independente, utilizando os conhecimentos adquiridos ao longo do curso para criar a estrutura, estilização e organização da página.

📚 Conceitos praticados

Durante o desenvolvimento do projeto foram aplicados diversos conceitos estudados no curso, entre eles:

* Estrutura semântica do HTML5
* Tags de agrupamento
* Cabeçalho e navegação
* Links e menus
* Box Model
* margin e padding
* border e border-radius
* width, max-width e min-width
* display
* Flexbox
* gap
* Alinhamento e centralização de elementos
* Responsividade
* Imagens responsivas
* Organização e estilização com CSS
* Sombras e efeitos visuais
* Transições

📱 Responsividade

O projeto foi desenvolvido tendo em consideração diferentes tamanhos de ecrã.

Foi utilizado um max-width para limitar a largura do conteúdo principal em ecrãs maiores e um min-width para evitar que a estrutura fique demasiado comprimida em dispositivos menores.

Também foram utilizadas técnicas como Flexbox e imagens responsivas para melhorar a adaptação do conteúdo.

🖼️ Galeria

O projeto possui uma galeria de imagens organizada com Flexbox, utilizando:

* display: flex
* flex-wrap: wrap
* justify-content
* align-items
* gap

Desta forma, as imagens podem reorganizar-se quando o espaço disponível diminui.

🎯 Objetivo

O principal objetivo deste projeto foi consolidar os conhecimentos adquiridos durante os estudos de HTML5 e CSS3 e ganhar experiência na criação de uma página web partindo de uma ideia própria.

Mais do que simplesmente reproduzir um exemplo do curso, o projeto foi desenvolvido procurando aplicar os conceitos aprendidos de forma independente.

📖 Aprendizagem

Este projeto ajudou-me a compreender melhor como HTML e CSS trabalham em conjunto, principalmente na organização estrutural da página, no posicionamento dos elementos e na criação de layouts adaptáveis.

Também serviu para desenvolver a capacidade de resolver problemas de layout através da experimentação e da compreensão do comportamento dos elementos no CSS.
